# DD 重裝作業系統

主選單選項 **12**。

## 功能

- **Linux 重裝** — 一鍵 DD 重裝為純淨 Linux 發行版
- **Windows 重裝** — 一鍵 DD 重裝為 Windows Server 或桌面版
- **自訂 ISO** — 透過 URL 載入自訂 DD 映像檔
- **架構選擇** — 支援 x86_64 與 ARM64
- **網路還原** — 重裝後自動設定網路

## 警告

此操作會**清除伺服器上所有資料**。請務必先備份，
並確保雲端廠商提供帶外管理主控台（VNC/iKVM）後再執行。

## 腳本

`scripts/dd_system.sh`
