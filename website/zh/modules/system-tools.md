# 系統工具

主選單選項 **1**。

## 功能

- **主機名管理** — 設定或變更伺服器主機名稱
- **時區設定** — 更新系統時區
- **DNS 設定** — 設定名稱伺服器
- **SSH 埠** — 變更 SSH 埠（含安全警告）
- **Swap 管理** — 自動建立/調整虛擬記憶體
- **BBR 壅塞控制** — 啟用 TCP BBR 提升吞吐量
- **Fail2ban** — 安裝設定 Fail2ban 防範暴力破解
- **IPv4 優先** — 設定 gai.conf 優先使用 IPv4
- **系統更新** — 透過偵測到的套件管理器更新系統

## 腳本

`scripts/system_tools.sh`
