# LDNMP 網站棧管理

主選單選項 **5**。

## 功能

- **完整 Docker 棧** — 透過 Docker Compose 佈署 Nginx + MySQL + PHP + Redis
- **網站管理** — 建立、刪除、管理虛擬主機
- **網域別名** — 為網站綁定多個域名
- **SSL 綁定** — 將 Let's Encrypt 憑證綁定至網站
- **反向代理** — 代理請求至後端服務
- **快取清除** — 清除 Nginx 快取
- **Brotli / Zstd 壓縮** — 啟用現代壓縮演算法
- **WAF 規則** — 每站台獨立設定防火牆規則

## 腳本

`scripts/web_manage.sh`
