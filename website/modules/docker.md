# Docker Management

Module option **6** from the main menu.

## Features

- **Docker installation** — auto-detect OS and install Docker Engine
- **Container monitoring** — list running containers with resource usage
- **Container management** — start, stop, restart, and remove containers
- **Image cleanup** — remove unused and dangling images
- **Docker Compose** — install and update Docker Compose plugin

## Script

`scripts/docker_manage.sh`
