# System Tools

Module option **1** from the main menu.

## Features

- **Hostname management** — set or change the server hostname
- **Timezone configuration** — update system timezone
- **DNS settings** — configure nameservers
- **SSH port** — change SSH port with security warnings
- **Swap management** — automatic swap creation/adjustment
- **BBR congestion control** — enable TCP BBR for better throughput
- **Fail2ban** — install and configure Fail2ban for brute-force protection
- **IPv4 preference** — configure gai.conf to prefer IPv4 over IPv6
- **System update** — update all packages via the detected package manager

## Script

`scripts/system_tools.sh`
