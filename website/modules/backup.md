# Backup & Cron Jobs

Module option **9** from the main menu.

## Features

- **Website backup** — full backup of `/home/web` directory
- **Website restore** — restore from a previous backup archive
- **Database backup** — dump MySQL/MariaDB databases
- **Cron task management** — schedule automated backups via crontab
- **Cleanup** — remove temporary files and system junk

## Script

`scripts/backup_manage.sh`
