# Modules Overview

The toolkit provides 13 feature modules, each accessible from the main menu.
Select a module below for detailed documentation.

| # | Module | Description |
|---|--------|-------------|
| 1 | [System Tools](/modules/system-tools) | Hostname, timezone, DNS, SSH port, swap, BBR, Fail2ban |
| 2 | [Firewall & WAF](/modules/firewall) | Port management, IP blacklist/whitelist, DDoS limits, geo-blocking (ipset) |
| 3 | [Kernel & BBR](/modules/kernel-bbr) | Native BBR, XanMod kernel (BBRv3), ELRepo upgrades |
| 4 | [SSL Certificates](/modules/ssl) | Let's Encrypt auto-renew, custom cert import, crontab integration |
| 5 | [LDNMP Web Stack](/modules/web-ldnmp) | Docker-based Nginx + MySQL + PHP + Redis, WAF/Brotli/Zstd |
| 6 | [Docker Management](/modules/docker) | Docker installation, container monitoring, image cleanup |
| 7 | [Docker App Store](/modules/app-store) | 11 one-click deployments |
| 8 | [FRP Tunneling](/modules/frp) | FRP client/server, port forwarding, Grafana/Prometheus monitoring |
| 9 | [Backup & Cron](/modules/backup) | `/home/web` backup/restore, scheduled tasks |
| 10 | [Benchmarks](/modules/benchmarks) | YABS, speedtest, streaming unlock check, nexttrace |
| 11 | [Cloudflare WARP](/modules/warp) | WARP gateway, SOCKS5 proxy, DNS optimization |
| 12 | [DD Reinstall](/modules/dd-system) | One-click OS reinstallation (Linux/Windows) |
| 13 | [Oracle Cloud](/modules/oracle-cloud) | Open iptables, remove Oracle agents, growpart resize |
