# Firewall & WAF Security

Module option **2** from the main menu.

## Features

- **Port management** — open or close ports with interactive prompts
- **IP blacklist / whitelist** — block or allow specific IP addresses
- **DDoS protection** — rate limiting via iptables rules
- **Country geo-blocking** — block traffic by country using ipset
- **Web Application Firewall (WAF)** — for LDNMP web stack sites

## Script

`scripts/firewall_manage.sh`
