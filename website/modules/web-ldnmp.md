# LDNMP Web Stack

Module option **5** from the main menu.

## Features

- **Full Docker stack** — deploys Nginx + MySQL + PHP + Redis via Docker Compose
- **Site management** — create, delete, and manage virtual hosts
- **Domain alias** — add multiple domains to a single site
- **SSL binding** — bind Let's Encrypt certificates to sites
- **Reverse proxy** — proxy requests to backend services
- **Cache purge** — clear Nginx cache
- **Brotli / Zstd compression** — enable modern compression algorithms
- **WAF rules** — per-site web application firewall configuration

## Script

`scripts/web_manage.sh`
