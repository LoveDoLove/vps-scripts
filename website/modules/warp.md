# Cloudflare WARP & Network Optimization

Module option **11** from the main menu.

## Features

- **Cloudflare WARP** — install and configure WARP for encrypted internet access
- **SOCKS5 proxy** — set up WARP as a local SOCKS5 proxy
- **DNS optimization** — configure fast DNS resolvers
- **WARP status** — check connection status and toggle on/off
- **IPv4 preference** — configure system to prefer IPv4

## Script

`scripts/warp_manage.sh`
