# Oracle Cloud Optimizations

Module option **13** from the main menu.

## Features

- **Open iptables** — open all ports in Oracle Cloud's default restrictive iptables
- **Remove Oracle agents** — uninstall Oracle Cloud monitoring and management agents
- **Disk resizing (growpart)** — automatically resize root partition to use all available disk space
- **Network reconfiguration** — fix IPv4/IPv6 networking after instance setup
- **DD reinstall network tools** — install tools needed for OS reinstallation on Oracle Cloud

## Script

`scripts/oracle_cloud.sh`
