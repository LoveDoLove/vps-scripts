# FRP Tunneling & Monitoring

Module option **8** from the main menu.

## Features

- **FRP client** — configure and run FRP client for exposing local services
- **FRP server** — set up the FRP server for clients to connect to
- **Port forwarding** — map remote ports to local services
- **Monitoring dashboard** — optional Grafana/Prometheus integration for FRP metrics
- **Systemd integration** — auto-start FRP as a system service

## Script

`scripts/frp_manage.sh`
