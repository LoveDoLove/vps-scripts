# Benchmarks & Network Tests

Module option **10** from the main menu.

## Features

- **YABS (bench.sh)** — comprehensive CPU, memory, and disk performance test
- **Speedtest** — network upload/download speed test using Ookla CLI or speedtest.net
- **Streaming unlock test** — check if streaming services (Netflix, Disney+, etc.) are available
- **Nexttrace** — MTR-style route tracing with ASN information
- **Ping test** — latency measurement to multiple global endpoints

## Script

`scripts/test_scripts.sh`
